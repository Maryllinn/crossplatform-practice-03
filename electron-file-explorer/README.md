**Преподаватель:** Бузыкова Юлия Сергеевна

## Возможности

- Отдельное окно `BrowserWindow` с интерфейсом HTML/CSS/JavaScript.
- Просмотр содержимого рабочего каталога через Node.js `fs.readdir`.
- Сохранение заметки через системный `dialog.showSaveDialog` и `fs.writeFile`.
- Безопасный мост `preload.js`: `contextBridge`, `ipcRenderer.invoke`, `ipcMain.handle`.
- Разделение main/renderer, `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`.
- Сборка Windows-установщика через `electron-builder`.

## Запуск

Нужен установленный Node.js LTS 24.x и npm. В терминале из папки проекта:

```powershell
npm install
npm start
```

При первом запуске список каталога загружается автоматически. Кнопка **Показать содержимое каталога** обновляет его. Чтобы сохранить текст, нажмите **Сохранить заметку**, выберите путь и подтвердите сохранение файла `.txt`.

## Сборка для Windows

```powershell
npm run dist
```

Установщик появится в папке `dist/`. Если Windows не даёт собрать NSIS из-за отсутствия права создания символических ссылок, включите режим разработчика Windows либо запустите терминал с соответствующими правами. Размер дистрибутива фиксируется отдельно по реальному результату сборки.

## Структура проекта

- `main.js` — главный процесс, окно, обработчики IPC, системный диалог, файловые операции.
- `preload.js` — ограниченный API для интерфейса.
- `renderer.js` — обработка кнопок и отображение каталога без прямого доступа к Node.js.
- `index.html`, `styles.css` — интерфейс.
- `package.json` — зависимости и правила сборки.
- `.gitignore` — исключение `node_modules/` и `dist/` из Git.

Согласно заданию исходный код размещается в репозитории `crossplatform-practice-03`, а отчёт приложен отдельно в формате DOCX.
